# VPS Kit 

Scripts and actions for setting up, hardening and maintaining my VPS.

Inspired by [unkn0w/noobs](https://github.com/unkn0w/noobs/tree/main)

## Installation

Note: This script must be run as root, so check what's inside it before you run it! 

```bash
curl -sSL https://raw.githubusercontent.com/sitek94/vpskit/main/init.sh | sudo bash
```
